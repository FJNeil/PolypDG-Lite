# Content needed before publication

## Identity

- Author name (Chinese and English)
- School / department / laboratory
- Contact email and GitHub username
- Advisor and collaborators, if applicable

## Research

- Final English and Chinese titles
- 150–250 word abstract
- Three concrete contributions
- Architecture or pipeline figure
- Paper / poster PDF, if public

## Evidence

- Dataset names and train/test protocol
- Main result table in CSV or spreadsheet form
- Parameters, FLOPs, latency or FPS, and test hardware
- Baseline names and citations
- At least 3 representative input / ground-truth / prediction groups
- Ablation study and failure cases

## Reproduction and release

- Source code and environment file
- Training, evaluation, and inference commands
- Checkpoint redistribution permission
- Dataset licensing / access notes
- Preferred code license
