# Presentation materials

This directory contains the conference-facing materials for PolypDG-Lite.

- [`PolypDG-Lite-conference-presentation.pdf`](PolypDG-Lite-conference-presentation.pdf): the 15-slide ICATI 2026 presentation authored and delivered by student researcher Shih-Wei Fan Chiang under the supervision of faculty advisor Yen-Ching Chang.
- [`framework-overview.png`](framework-overview.png): a web-ready preview of the four-stage framework, extracted from the presentation.

The presentation covers the clinical motivation, six-center LOCO protocol, U-Net baseline diagnosis, consistency-trained SegFormer-B2 teacher, SegFormer-B0 knowledge distillation, and FP16 deployment validation.

Return to the [repository overview](../README.md) for verified result tables, code navigation, reproducibility scope, and responsible-use notes.
